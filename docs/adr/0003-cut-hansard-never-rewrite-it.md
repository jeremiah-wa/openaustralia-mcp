# Cut Hansard, never rewrite it

Hansard is licensed CC BY-NC-ND, which allows no derivatives. So the server may cut, excerpt and paginate it, but never paraphrases or summarises it, even when a debate is too long for one result. Long debates are paged with `read_debate`, and summarising is left to the client model.

That last part is an assumption, not a legal finding. The licence defines a derivative as "material in any form that is created by editing, modifying or adapting the Work, a substantial part of the Work, or the Work and other pre-existing works", and we haven't established whether a model's summary for its user counts as one.
